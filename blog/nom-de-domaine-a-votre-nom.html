Nom de domaine : pourquoi il doit toujours être à votre nom

Votre nom de domaine est l'adresse de votre site. Pourquoi il doit être enregistré à votre nom, comment le vérifier, et ce qui se passe si vous changez de prestataire.

Publié le 3 novembre 2026 · 4 min de lecture · Sakura Group

Le nom de domaine, c'est l'adresse de votre site : votre-entreprise.fr. Il apparaît sur vos cartes de visite, vos e-mails, vos véhicules, vos réseaux. C'est un élément de votre marque, au même titre que votre logo.

Le piège classique

Il arrive que le prestataire qui crée le site enregistre le nom de domaine à son propre nom. Tant que tout va bien, personne ne le remarque. Le jour où vous voulez changer de prestataire, vous découvrez que votre adresse ne vous appartient pas, et qu'il faut négocier pour la récupérer.

Comment vérifier à qui appartient votre domaine

Demandez simplement à votre prestataire : « Le domaine est-il enregistré à mon nom ? ». Vous pouvez aussi consulter l'annuaire public des noms de domaine (recherche « whois ») : pour les particuliers, certaines informations sont masquées, mais votre prestataire doit pouvoir vous montrer le titulaire.

Ce qu'il faut demander dès le départ

  • Le domaine est enregistré à votre nom (ou au nom de votre entreprise).
  • Vous savez chez quel registraire il est (OVH, Gandi, IONOS…).
  • Si vous partez, le prestataire vous donne le code de transfert et les fichiers du site.

Notre règle chez Sakura Group

Le nom de domaine de nos clients est enregistré à leur nom. Si vous arrêtez l'accompagnement, on vous transfère votre domaine et les fichiers de votre site. Votre adresse reste la vôtre, quoi qu'il arrive.
